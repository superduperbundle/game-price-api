# SuperDuperBundle Game Prices for Playnite

Right-click one or more games in [Playnite](https://playnite.link/) and choose **Check key prices on SuperDuperBundle**: you see the lowest listed PC key price (US dollars), the store, how many stores were compared and when the price was checked. **Yes** opens the full comparison on [superduperbundle.com](https://superduperbundle.com/).

**Install:** download the `.pext` from the [latest release](https://github.com/superduperbundle/game-price-api/releases/tag/playnite-v1.0.0) and open it (or drag it onto the Playnite window). Playnite 10 (SDK 6.9+).

**Privacy:** only the selected games' Steam app IDs (Steam library games) or names are sent to the public [Game Price API](https://superduperbundle.com/tools/api/); nothing is stored by the add-on. Listed prices: stores set fees and the final total at checkout. Code: MIT. Built by `.github/workflows/playnite.yml`.
